📖 Comment utiliser :
  1. Ouvrez un Google Doc
  2. Cherchez la barre d'outils flottante "🎬 Extraits Vidéo"
  3. Sélectionnez du texte
  4. Cliquez sur S1, S2, etc. pour marquer
