La barre d'outils est disponible sur vos Google Docs.

📖 Comment utiliser :
  1. Ouvrez un Google Doc
  2. Sélectionnez du texte
  3. Clic droit → "🎬 Marquer segment" → S1, S2, etc.
  4. Ou utilisez la barre d'outils flottante
  5. Cliquez "✅ Marquer comme PRÊT" quand terminé

💡 Nouveau : Plus besoin de copier le texte ! Sélectionnez et faites clic droit pour marquer directement.

Astuce : La barre d'outils est déplaçable.
